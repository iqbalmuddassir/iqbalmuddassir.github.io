Works offline No account No tracking
01

Open and test any link

Paste or type a link into the composer and launch it immediately — https, a custom scheme like myapp://, mailto, tel, whatever you're working with. If nothing on the device can open it, LinkLab tells you plainly instead of failing silently.

  • Scheme, host, and parameter count shown at a glance before you launch
  • Custom schemes are first-class — built for links Safari won't even open
02

File a link without launching it

Save a link to your lab log with an optional label, without opening it. Useful for cataloguing test links, deep links you want to hand off, or anything you want to keep around without triggering it yet.

03

Turn any link into a QR code

Generate a QR code for a saved or in-progress link with one tap. Share it as a PNG, or save a branded copy straight to Photos — hand it to someone else's device without them typing a single character.

04

A local log, searchable and pinnable

Every link you launch or file lands in one searchable log, newest first. Re-launching or re-saving the same link updates its entry instead of duplicating it, so your history stays clean no matter how many times you're testing the same deep link.

  • Swipe or long-press any entry to pin it — pinned links stay at the top, above the newest-first order
  • Search by label or URL to find a link in a log of any size

Runs entirely on your device

LinkLab has no network code — no server, no account, no analytics, no third-party SDK. QR codes are generated on-device, and Photos access is add-only, requested only the moment you choose to save an image.
