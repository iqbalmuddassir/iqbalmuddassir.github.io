Capabilities

What stays one click away

A compact sidebar keeps project context while the main pane handles each workflow.

  • 01 · Issues

    Triage without context-switching

    Browse assigned or created issues, filter by Open / In progress / Done, and change status from the popover.

  • 02 · Reviews

    Code reviews at a glance

    See review title, number, and source → target branches; open the review in Space with one click.

  • 03 · ToDos

    Personal checklist in the bar

    Toggle done / undone and delete items without opening the full Space client.

  • 04 · Projects

    Multi-project switcher

    Pick the active Space project from the sidebar; counts and lists refresh for that project.

  • 05 · Auth

    Org + token via Keychain

    Store *.jetbrains.space credentials securely; Accessibility-style Keychain prompts keep the secret off disk in plaintext.

Build

How it sits on macOS

Native accessory app — status item + transient popover, not a docked window.

SwiftUI + AppKit

NSStatusItem hosts an NSPopover with a SwiftUI NavigationView sidebar.

Space HTTP client

Typed DTOs for issues, reviews, todos, and project lists against the Space API.

Defaults + Keychain

Org / project prefs via Defaults; API token read and written through Keychain.
